# File Sharing Utility Tests

[![Coverage Status](https://coveralls.io/repos/github/koiri143/file-sharing-tests/badge.svg?branch=main)](https://coveralls.io/github/koiri143/file-sharing-tests)

This project uses Vitest to test 10 JavaScript utility functions for filenames, file sizes, and link expiration dates.

## Run the tests

Use Node.js 24 and run these commands in the project folder:

```sh
npm ci
npm test
```
